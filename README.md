# JavaScript Mini Games

Mini proyecto realizado con JavaScript para practicar estructuras de control, bucles, arrays, condicionales, funciones y números aleatorios.

## Juegos incluidos

### 🎵 Playlist
Permite crear una playlist personalizada ingresando un nombre y una lista de canciones.

### 💲 Cara o Cruz
El usuario elige cara o cruz y compite contra un resultado aleatorio. El juego registra la racha actual y la mejor racha obtenida.

### ⚖️ Adivina el Número
El usuario debe adivinar un número aleatorio entre 1 y 10. El programa indica si el número buscado es mayor o menor.

### ✊🤚✌️ Piedra, Papel o Tijera
Juego clásico contra la computadora con múltiples rondas y sistema de puntuación.

## Conceptos practicados

- Variables y constantes
- Condicionales (`if`, `else`, `switch`)
- Bucles (`for`, `while`)
- Arrays
- Funciones
- Métodos de strings
- Números aleatorios (`Math.random`)
- Interacción con el usuario mediante `prompt` y `alert`
